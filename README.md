# SaveBili Desktop

SaveBili Desktop 是一个基于 pywebview 和 SaveAny 的 B 站视频下载桌面应用。它提供了聊天式交互界面，支持扫码登录、多 Cookie 管理、视频预览、保存到本地等功能，界面采用毛玻璃与渐变风格。

## 功能特性

- 聊天式下载：在对话界面中输入 BV 号或视频链接即可开始下载，并实时显示下载进度、速度和封面。
- 动态进度盘：下载过程中显示毛玻璃风格的速度表式进度条。
- 视频管理：已下载的视频以卡片形式展示封面，支持预览、保存到系统下载目录、删除。
- 扫码登录：内置二维码生成，使用 B 站 App 扫码自动保存 Cookie。
- Cookie 管理：支持手动添加 SESSDATA 或完整 Cookie，多 Cookie 优先级管理，数据安全存储在系统钥匙串中。
- 设置面板：可配置默认画质（80=1080P, 112=1080P+ 等）、自定义保存目录。
- 本地媒体服务器：通过内置 HTTP 服务器提供视频和封面预览，支持 Range 请求。
- 数据持久化：媒体库、Cookie 元数据、配置均保存在用户目录（Windows 为 `~/.savebili`），使用系统钥匙串加密 Cookie 字符串。

## 安装与运行

### 环境要求

- Windows 10/11（其他平台暂未测试）
- Python 3.10+（推荐 3.11 或 3.12）
- Microsoft Edge WebView2 Runtime（Windows 11 通常已预装）

### 安装依赖

```bash
pip install pywebview requests qrcode pillow keyring
```

### 运行

```bash
python SaveBili_Desktop.py
```

### 使用说明

--- 下载视频
- 打开“下载对话”面板
- 在输入框中输入 B 站视频链接或 BV 号（例如 BV1xx411c7mD）。
- 点击发送或按回车，SaveAny酱~ 会开始解析并下载。
-  下载过程中，对话区域会动态显示封面、标题、进度盘和速度。
-下载完成后，会出现“预览视频”按钮，点击可播放视频。

--- 扫码登录
- 切换到“扫码登录”面板。
- 页面会自动生成二维码，使用 B 站 App 扫码并确认。
- 登录成功后 Cookie 自动保存到系统钥匙串，下载时自动使用优先级高的Cookie。

--- 手动添加 Cookie
- 切换到“Cookie 管理”面板。
- 在文本框中粘贴 SESSDATA 值或完整 Cookie 字符串（如 SESSDATA=xxx; bili_jct=yyy）。
- 可填写备注和优先级（数字越小越优先）。
- 点击“添加 Cookie”，插件会自动补全前缀。

--- 视频管理
- 切换到“视频管理”面板，查看所有已下载视频。
- 点击“预览”可播放视频（使用内置 HTTP 服务器）。
- 点击“保存到下载目录”会将视频复制到系统下载文件夹（自动读取注册表路径）。
- 点击“删除”可移除视频及其封面文件。

--- 设置
- 切换到“设置”面板。
- 设置默认画质代码（如 80 代表 1080P）。
- 设置保存目录（留空则仅保存在媒体库，不额外复制）。

### 注意事项
1.请勿泄露 Cookie，它相当于账号凭证 ! ! !

2.下载高清视频需要 B 站账号具备相应权限（如大会员）。

3.本项目仅供学习交流使用，请遵守 B 站服务条款，合理使用下载功能。

4.如果视频预览失败，请确认系统已安装 Edge WebView2 Runtime。
